What it does

兩件事,做晒晒。

冇多餘功能,冇你唔識嘅設定——淨係將搵工入面最煩嘅兩步自動化。

01 · SAVE

一鍵儲存眼前嗰個職位

喺 LinkedIn、JobsDB、CTgoodjobs 嘅職位詳情頁,會浮出一個「Save to JobAI」掣。撳落去, extension 會幫你抽好職位名、公司、地點、薪酬範圍、描述同網址。你睇一眼、想改就改,然後儲存。 已經存過嘅職位會自動認出,唔會重複。

02 · AUTOFILL

自動填申請表

打開一張申請表,喺 extension 彈窗撳「自動填申請表」,你自己嘅 JobAI 檔案(姓名、電郵、電話、 城市、現職職位、現職公司、技能)就會填入對應嘅空白欄位。已經有內容嘅欄位唔會被覆蓋, extension 亦永遠唔會幫你㩒交表——一定係你自己睇完再交。

Privacy

用你自己嘅登入身分,冇第三方。

Extension 唔會問你攞密碼,亦冇 API key。職位只會寫入你自己嘅 JobAI 帳戶。

  • 只喺你撳「儲存」嗰一刻先讀當前職位頁
  • 唔追蹤瀏覽紀錄、唔收集分析數據
  • 唔會出售或轉交任何資料畀第三方
  • 登入 token 只留喺你部機,移除 extension 即清走
